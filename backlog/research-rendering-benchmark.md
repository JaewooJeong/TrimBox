## 즉시 개선 3총사 (7.0점 목표)

### 1. 빛 강화
- 트렁크 LED 조명 하이라이트 강화
- 짐 상단면 하이라이트 추가 (광원 방향 시뮬레이션)
- 금속/플라스틱 반사 강조

### 2. 바닥 밝기
- 바닥 그라디언트 대비 강화
- 트렁크 입구 쪽 자연광 유입 효과
- 바닥-벽 경계 앰비언트 오클루전 강화

### 3. 그림자 blur
- 짐 아래 소프트 그림자 추가 (MaskFilter.blur)
- 바닥 접촉면 그림자 -> 짐이 "떠있지 않은" 느낌
- 그림자 크기/투명도 높이에 비례

### Phase 4+ Three.js 하이브리드 방안
- 포토리얼리즘 필요 시 **Three.js 하이브리드 권장**
- Flutter Web 내 iframe 또는 Platform View로 Three.js 캔버스 임베드
- 3D 뷰는 Three.js, UI/인터랙션은 Flutter
- glTF 모델 로딩, PBR 머티리얼, 실시간 그림자
- 단점: 플랫폼 복잡도 증가, 모바일 성능 고려 필요
