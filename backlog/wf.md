## 2. 주요 컴포넌트 설명

### (1) **App Bar**

* 좌측: 뒤로가기 버튼 ←
* 중앙: 앱명 **TrimBox Simulator**
* 우측: 뷰 모드 전환 버튼 (아이콘 `3D` ↔ `2D`)

### (2) **Main Area (아이소메트릭 트렁크 뷰)**

* 바닥: 짙은 회색 (`#2E2E2E`)
* 그리드 라인: 얇은 흰색 (`10cm 단위`)
* 휠하우스: 양쪽에 직육면체 돌출 (`#AAAAAA`)
* 상자(TrimBox):

  * 기본 색상: 파스텔톤 (랜덤)
  * 선택 시: 테두리 파란색, 크기 라벨 표시

### (3) **Bottom/Side Panel**

* 버튼:

  * **+ 박스 추가** → 팝업 (W, D, H 입력)
  * **저장**, **불러오기**, **스크린샷**
* **Box List**:

  * 상자 정보 (W×D×H)
  * 버튼 \[회전], \[삭제]

---

## 3. 인터랙션 플로우 (Figma Prototype 연결 팁)

* **+박스 추가 버튼 → 팝업 오버레이**

  * 입력 필드 (가로/세로/높이 cm)
  * 확인 → 새로운 박스 생성되어 트렁크 뷰에 등장

* **상자 선택**

  * 테두리 하이라이트
  * Box List에서 해당 박스 항목도 강조

* **회전 버튼 클릭**

  * 박스가 Y축 기준으로 90° 회전

* **충돌 시**

  * 겹치는 박스 테두리를 **빨간색** 처리

## 4. 색상 / 디자인 토큰 제안

* **Background**: `#1C1C1C` (다크)
* **Trunk Floor**: `#2E2E2E`
* **Wheelhouse**: `#A9A9A9`
* **Grid Line**: `#CCCCCC` (opacity 0.3)
* **Boxes**: 파스텔톤 (`#FFB3BA`, `#BAE1FF`, `#BAFFC9`, `#FFFFBA`)
* **Highlight (선택됨)**: `#4DA3FF`
* **Error (충돌)**: `#FF4D4D`

---

## 5. Figma 작업 팁

* **Frame 구조**

  * Frame → Auto Layout (상단 Bar, Main, Bottom Panel)
* **Main Area**

  * Rectangle + 아이소메트릭 Transform (X: 30°, Y: 30°)
  * Wheelhouse: Rectangle 2개, 위쪽에 배치
  * Box: Rectangle, Drop Shadow + 반투명 Fill
* **Prototype**

  * 버튼에 Interaction 연결 (박스 생성 → 새로운 박스 Frame 나타나도록)
