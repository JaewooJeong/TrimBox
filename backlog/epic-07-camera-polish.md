# Epic 07: 카메라 & 인터랙션 폴리싱

## 배경
Epic 06에서 자유 궤도 카메라(free orbit)를 구현했으나, E2E 테스트에서 몇 가지 개선점 발견.

## 발견된 이슈 (E2E 테스트 결과)
1. **극단 각도(±90°+)에서 렌더링 품질 저하** — 거의 옆에서 보면 트렁크 바닥이 선처럼 보임
2. **피치(상하 각도) 조절 없음** — 현재 수평 yaw만 지원, 위/아래에서 보는 각도 고정
3. **줌 제한 없음** — 마우스 휠로 무한 확대/축소 가능, 적정 범위 제한 필요
4. **카메라 전환 애니메이션** — Q/E 45° 스냅 시 부드러운 이징 적용 필요
5. **터치 디바이스 대응** — 2-finger pinch zoom, 2-finger rotate 미구현

## 스토리

### 7.1 피치 각도 지원
- 상하 드래그 시 isometric 피치 각도를 15°~45° 범위로 조절
- `toIso()`에 피치 파라미터 추가
- 기본값: 30° (현재 고정값)

### 7.2 줌 범위 제한
- 최소/최대 스케일 클램핑 (0.5x ~ 3.0x)
- 줌 시 마우스 포인터 위치 기준 확대/축소 (zoom-to-cursor)

### 7.3 터치 제스처 지원
- 2-finger rotate → yaw 변경
- 2-finger pinch → 줌
- 1-finger drag on box → 박스 이동 (현재 left-click과 동일)
- Long press → 박스 선택/컨텍스트 메뉴

### 7.4 카메라 프리셋 뷰
- 더블클릭 '0' 키 → 기본 뷰 (yaw=0, pitch=30°, zoom=auto)
- 숫자 키 1~4 → 전면/좌측/우측/상단 뷰 프리셋
