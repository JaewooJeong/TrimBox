# TrimBox B2B 파트너십 모델 리서치 (2026-03-07)

## 타겟 파트너 브랜드

### 하드/소프트케이스 브랜드
- **아이캠퍼** (iKamper): 루프탑텐트, 한국 기반 글로벌 브랜드
- **코베아** (Kovea): 국내 캠핑 장비 1위, 텐트/쿨러/테이블 등 풀라인업
- **카즈미** (Kazmi): 중저가 캠핑 장비, 국내 온라인 판매 강세
- **툴레** (Thule): 루프박스/캐리어 글로벌 1위, 차종별 호환성 데이터 보유
- **야키마** (Yakima): 루프 캐리어/박스, 북미 시장 강세
- **도메틱** (Dometic): 쿨러/냉장고, 프리미엄 아웃도어 가전

## 제휴 모델 벤치마크

### Thule Fit Guide 모델
- 툴레는 **차종별 호환성 체크 시스템** 운영 중
- 차량 연식/모델 입력 -> 호환 제품 목록 제공
- TrimBox에 적용: 차종 선택 시 해당 트렁크에 맞는 장비 추천

### 스노우피크 제휴
- 스노우피크 **제휴 문의 페이지** 운영 중
- 브랜드 콜라보 적극적 (의류, 음료, 숙박 등 이종 산업 협업)
- TrimBox 내 스노우피크 장비 프리셋 제공 -> 구매 연결

### 헬리녹스 x GS25 사례
- 헬리녹스 x GS25 콜라보 **3시간 완판** 사례
- 캠핑 브랜드의 콜라보 마케팅 효과 입증
- TrimBox 브랜드 스폰서 프리셋으로 유사 효과 가능

## 수익 모델

### 1. 어필리에이트 커미션
- Backcountry: **8%** 커미션
- GSI Outdoors: **15%** 커미션
- 쿠팡 파트너스: 3%
- TrimBox 내 장비 프리셋 -> "구매하기" 링크 -> 커미션 수익

### 2. 브랜드 스폰서 프리셋
- 특정 브랜드 장비를 프리셋 상단에 노출
- 브랜드 로고/컬러로 커스텀 렌더링
- 월/분기 단위 스폰서십 계약

### 3. 프리미엄 구독
- 무료: 기본 차종 3개 + 장비 50개
- 프리미엄: 전체 차종 + 전체 장비 + 자동배치 + 공유카드
- 월 3,900원 / 연 29,000원 예상

### 4. 데이터 판매
- 장비 적재 패턴 데이터 (익명화)
- 차종별 인기 장비 조합
- 캠핑 시즌별 트렌드 분석
- 자동차/장비 제조사 대상 B2B 데이터 라이선싱

## 루프 카고박스 시장

- 글로벌 루프 카고박스 시장 **$12억 -> $24억** (CAGR 8.5%)
- 트렁크 공간 부족 -> 루프박스 수요 증가
- TrimBox에서 "트렁크에 안 들어감" 판정 -> 루프박스 추천 연계 가능

## OEM 파트너십 기회

- **현대/기아 트렁크 시뮬레이터 제공 이력 없음**
- 차량 구매 과정에서 트렁크 시뮬레이터 제공 = 구매 전환율 향상
- 현대/기아 웹사이트 또는 딜러 태블릿에 TrimBox 임베드
- 자동차 OEM 대상 B2B SaaS 모델 가능
