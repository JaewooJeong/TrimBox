# Epic 11: 테스트 커버리지 강화

## 배경
Epic 06에서 카메라 시스템, 렌더러, 모델을 대폭 변경했으나 테스트가 업데이트되지 않음.
PRD 목표: 95% 단위 테스트 커버리지.

## 스토리

### 11.1 모델 테스트 업데이트
- `TrunkSpace` 새 필드 테스트 (bodyWidth, trunkLipHeight 등)
- `bodyExtX` 계산 검증
- JSON 직렬화/역직렬화 테스트 (새 필드 포함)
- 이전 포맷 JSON 역호환성 테스트

### 11.2 카메라 시스템 테스트
- `toIso()` yaw 회전 정확성 검증
- `isFaceVisible()` 다양한 각도에서의 정확성
- `computeCenter()` 바운딩 박스 계산 검증
- 역방향 투영 (`_screenToWorldDX/DZ`) 정확성

### 11.3 충돌 감지 테스트
- 회전된 뷰에서의 충돌 감지 일관성
- 스태킹 상태에서의 충돌 판정
- 휠하우스 충돌 경계값 테스트

### 11.4 위젯 테스트
- 궤도 카메라 제스처 (우클릭 드래그)
- Q/E 키 회전 애니메이션
- 박스 추가/삭제/회전 UI 흐름
- 프리셋 변경 시 상태 초기화

### 11.5 통합 테스트
- 전체 시나리오: 프리셋 선택 → 박스 추가 → 배치 → 저장 → 불러오기
- 카메라 회전 중 박스 드래그 정확성
- 다양한 화면 크기에서의 렌더링

## 우선순위
High — 코드 안정성과 리팩터링 자신감에 직결

## 의존성
- Epic 06 (완료) — 변경된 코드 대상
