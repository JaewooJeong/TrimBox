# Epic 09: 자동 배치 알고리즘

## 배경
PRD 2단계 기능: "자동 배치 추천 알고리즘". 사용자가 박스 목록을 입력하면 최적 배치를 자동 계산.

## 목적
- 수동 배치의 시행착오 감소
- 공간 효율 최적화 (가장 많은 짐을 적재하는 배치 추천)
- 여러 배치 옵션 비교 가능

## 스토리

### 9.1 기본 자동 배치
- "자동 배치" 버튼 → 현재 박스 목록을 최적 위치에 자동 배치
- 알고리즘: Bottom-Left-Fill (BLF) 또는 Shelf 알고리즘
- 휠하우스 회피 로직 포함
- 높이 제한 준수 (스태킹 시 트렁크 높이 초과 방지)

### 9.2 스태킹 최적화
- 큰 박스 위에 작은 박스 자동 스태킹
- 무게중심 안정성 고려 (선택)
- 스태킹 가능 조건: 아래 박스 면적의 50%+ 겹침

### 9.3 배치 제안 UI
- 자동 배치 결과를 애니메이션으로 보여줌 (박스가 하나씩 배치되는 효과)
- "다른 배치 보기" → 대안 배치 순환
- 수동 조정 후 "재최적화" 가능

### 9.4 적재 불가 알림
- 모든 박스가 들어가지 않을 경우 경고
- 들어가지 못한 박스 목록 표시
- "우선순위 설정" → 중요한 박스 먼저 배치
