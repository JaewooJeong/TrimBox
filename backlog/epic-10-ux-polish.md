# Epic 10: UX 폴리싱 & 접근성

## 배경
E2E 테스트 및 디자인 문서 검토 결과 발견된 UX 개선 사항 모음.

## 스토리

### 10.1 라이트 모드 지원
- 디자인 토큰에 정의된 Light 테마 구현
- 시스템 설정 자동 감지 (prefers-color-scheme)
- 수동 토글 옵션

### 10.2 박스 복제 기능
- 박스 선택 후 "복제" 버튼 → 동일 크기/색상의 박스 생성
- 키보드 단축키: Ctrl+D
- 복제된 박스는 원본 옆에 배치 (겹치지 않는 위치)

### 10.3 박스 일괄 작업
- 다중 선택 (Shift+클릭 또는 드래그 선택)
- 선택된 박스 일괄 삭제/이동/회전
- 그룹 드래그 (여러 박스 동시 이동)

### 10.4 토스트 알림 시스템
- 저장 성공/실패 피드백
- 충돌 경고 토스트
- 자동 스냅 알림 ("10cm 그리드에 정렬됨")
- 스태킹 성공 피드백

### 10.5 반응형 레이아웃
- 모바일: 하단 패널 (박스 리스트)
- 태블릿: 접을 수 있는 사이드 패널
- 데스크톱: 현재 우측 패널 유지
- 브레이크포인트: 600px (모바일), 900px (태블릿)

### 10.6 키보드 접근성
- Tab 키로 UI 요소 간 이동
- 방향키로 선택된 박스 미세 이동 (1cm 단위)
- Shift+방향키 → 10cm 단위 이동
- 스크린 리더 지원 (ARIA 라벨)

## 우선순위
Medium — 사용성과 접근성 향상
