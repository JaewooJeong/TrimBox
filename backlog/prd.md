## 🚀 PRD (Product Requirements Document)

### 1. 개요

* 제품명: **TrimBox Simulator**
* 목적:

  1. 사용자가 자신이 가진 상자의 크기를 입력하고, SUV 트렁크 공간(아이소메트릭 뷰)에 배치해볼 수 있음.
  2. 공간 효율 확인, 상자 배치 시뮬레이션.
  3. 1단계는 수동 배치, 2단계는 자동 배치 추천 알고리즘.

---

### 2. 주요 기능

1. **트렁크 바닥/매트 표현**

   * 아이소메트릭 직육면체 형태 (가로×세로×높이 → 실제 트렁크 치수 기반)
   * 휠하우스 돌출부(양쪽) 단순 직육면체로 표시
   * 바닥 그리드(10cm 단위) 표시 → 정렬감

2. **TrimBox(상자) 생성/관리**

   * (W, D, H) 입력 → 박스 생성
   * 색상 랜덤 부여 (겹칠 때 구분 용이)
   * 회전 (90°), 이동(드래그), 삭제

3. **배치/충돌 처리**

   * 바닥 위 배치 (Snap-to-grid)
   * 다른 박스와 겹치면 경고 색상(빨강)
   * 경계 밖 배치 불가 처리

4. **저장/불러오기**

   * JSON 구조로 scene 저장
   * 불러오기 시 그대로 재현

5. **향후 확장**

   * 자동 최적 배치 (Bin Packing 알고리즘)
   * 2D 뷰/리스트 뷰 (평면도 병행)
   * AR 확장 (실제 트렁크에 상자 오버레이)

---

### 3. 사용자 시나리오

1. 사용자는 앱 실행 후 \*\*트렁크 공간(아이소메트릭 뷰)\*\*를 본다.
2. **+박스 추가** 버튼 → 크기 입력(W×D×H).
3. 상자가 바닥에 생성 → 드래그 & 드롭으로 위치 이동.
4. 충돌 시 빨간색 테두리 → 조정 필요.
5. 여러 상자 배치 후 → 저장/스크린샷/공유.

## 🎨 디자인 계획

### 1. 화면 레이아웃

* 상단: 앱 타이틀/모드 전환 (3D뷰 / 평면도)
* 중앙: 아이소메트릭 3D 트렁크 공간
* 하단/우측: **상자 리스트 패널**

  * 각 상자: W×D×H, 색상, 삭제, 회전 버튼

### 2. 비주얼 톤

* **트렁크 바닥**: 짙은 회색(다크그레이) + 그리드 라인
* **휠하우스 부분**: 옅은 회색 돌출 블록
* **상자**: 파스텔톤 (투명도 70%) → 겹침 시 시각적 구분
* **상자 선택 상태**: 파란색 테두리, 크기 라벨 표시

### 3. 인터랙션

* 드래그: 마우스/터치 → X-Z 평면 이동
* Snap-to-grid: 10cm 단위 자동 보정
* 회전: 버튼 누를 때마다 90° 회전
* 충돌 시 → 빨간색 하이라이트

---

### 4. 프로토타입 예시 플로우

1. 기본 화면: 아이소메트릭 트렁크 (매트 + 휠하우스)
2. “상자 추가” → 팝업 입력 (가로/세로/높이)
3. 생성된 상자가 트렁크 내부에 나타남
4. 드래그/회전 → 적재 위치 결정
5. 저장/공유

---

📌 핵심은 **풀 3D 복잡성은 버리고, 아이소메트릭+Snap+충돌 체크만으로도 충분히 시각적 & 직관적인 시뮬레이터**라는 점입니다.
