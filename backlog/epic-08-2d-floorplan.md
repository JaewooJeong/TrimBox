# Epic 08: 2D 평면도 뷰

## 배경
PRD에 명시된 "평면도(2D) 뷰" 기능. 아이소메트릭 3D 뷰와 병행하여 위에서 내려다보는 2D 평면도를 제공.

## 목적
- 정밀한 박스 배치 시 3D 왜곡 없이 정확한 위치 파악
- 복잡한 레이아웃에서 빈 공간 식별 용이
- 인쇄/공유용 깔끔한 레이아웃 이미지 생성

## 스토리

### 8.1 2D 뷰 토글
- 상단 바에 3D/2D 뷰 전환 토글 버튼
- 2D 뷰: 직교(orthographic) 탑다운 뷰
- 트렁크 바닥 + 휠하우스를 직사각형으로 표시
- 박스를 색상 코딩된 직사각형으로 표시 (이름 라벨 포함)
- 10cm 그리드 표시

### 8.2 2D 뷰 인터랙션
- 동일한 드래그 앤 드롭으로 박스 이동
- 동일한 충돌 감지 및 시각적 피드백
- 마우스 휠 줌 + 패닝
- 3D 뷰와 상태 동기화 (한쪽에서 이동하면 다른 뷰에도 반영)

### 8.3 치수 오버레이
- 박스 간 거리 표시 (스마트 가이드)
- 빈 공간 크기 표시
- 벽까지 남은 거리 표시

### 8.4 듀얼 뷰 모드 (선택)
- 화면 분할: 좌=3D, 우=2D 동시 표시
- 한쪽 뷰에서 박스 클릭 시 다른 뷰에서도 하이라이트
