# Epic 01: TrimBox MVP 완성도 향상

## 개요

TrimBox Simulator의 1차 렌더링/인터랙션 기반이 완성된 상태에서, **Save/Load 고도화**, **박스 관리 UX 개선**, **UI 세련화**를 통해 MVP 품질을 달성한다.

**현재 구현 완료:**
- 아이소메트릭 3D 트렁크 뷰 (벽, 바닥, 그리드, 림, AO)
- 박스 CRUD + 커스텀 치수 입력 (AddBoxDialog)
- 드래그 & 드롭 + 10cm 그리드 스냅
- 충돌 감지 (박스 간, 경계, 휠하우스) + 빨간 테두리
- 90도 회전, 키보드 단축키 (방향키, R, Delete)
- 트렁크 프리셋 전환 (SUV/Sedan/Van/Custom)
- Save/Load (JSON 클립보드)
- 공간 효율 표시 (점유율 %)

---

## 스토리 목록

### Story 1: Save/Load 파일 기반 전환 (P0 - 필수)
**목표:** 클립보드 전용 → 파일 다운로드/업로드로 전환하여 실제 사용 가능한 저장/불러오기 제공

**인수 조건 (AC):**
- AC1.1: "저장" 클릭 시 `.trimbox.json` 파일이 브라우저 다운로드로 저장된다
- AC1.2: "불러오기" 클릭 시 파일 선택 다이얼로그가 열리고, `.json` 파일을 선택하면 씬이 복원된다
- AC1.3: 잘못된 JSON 파일 로드 시 사용자에게 에러 스낵바가 표시된다
- AC1.4: 기존 클립보드 방식은 제거한다 (파일 방식으로 완전 대체)

**기술 노트:**
- 웹: `dart:html`의 `AnchorElement` + `Blob`으로 다운로드, `FileUploadInputElement`로 업로드
- `JsonIO` 유틸 수정

---

### Story 2: 박스 프리셋 템플릿 (P1 - 높음)
**목표:** 자주 쓰는 박스 크기를 원클릭으로 추가할 수 있는 프리셋 제공

**인수 조건 (AC):**
- AC2.1: AddBoxDialog에 "프리셋" 드롭다운이 추가된다
- AC2.2: 프리셋 선택 시 가로/세로/높이 필드가 자동으로 채워진다
- AC2.3: 기본 프리셋 목록: 소형 캐리어(36×25×55), 중형 캐리어(45×28×65), 캠핑 박스(60×40×40), 아이스박스(50×35×35), 커스텀(기존 직접 입력)
- AC2.4: 프리셋 선택 후에도 치수를 수동 수정할 수 있다

**기술 노트:**
- `AddBoxDialog`에 프리셋 데이터 리스트 + DropdownButton 추가
- 기존 직접 입력 플로우는 그대로 유지

---

### Story 3: Undo/Redo 기능 (P1 - 높음)
**목표:** 박스 추가/삭제/이동/회전 작업의 실수를 되돌릴 수 있게 한다

**인수 조건 (AC):**
- AC3.1: Ctrl+Z로 마지막 작업을 취소할 수 있다
- AC3.2: Ctrl+Shift+Z (또는 Ctrl+Y)로 취소한 작업을 다시 실행할 수 있다
- AC3.3: Undo/Redo 스택은 최대 50개까지 저장된다
- AC3.4: 지원 작업: 박스 추가, 삭제, 이동(드래그 종료 후), 회전
- AC3.5: 새 작업 수행 시 Redo 스택은 초기화된다

**기술 노트:**
- `_boxes` 리스트의 스냅샷 기반 Command 패턴 또는 간단한 상태 스냅샷 스택
- `SimulatorScreen`에 `_undoStack`, `_redoStack` 추가
- `KeyboardListener`에 Ctrl+Z/Ctrl+Shift+Z 핸들러 추가

---

### Story 4: UI 세련화 — 다이얼로그 & 패널 디자인 (P1 - 높음)
**목표:** 디자인 가이드(uiux.md)에 맞게 다이얼로그와 패널의 시각적 품질을 높인다

**인수 조건 (AC):**
- AC4.1: AddBoxDialog에 박스 미리보기(색상 사각형 + 예상 크기 시각화)가 표시된다
- AC4.2: 박스 색상을 사용자가 직접 선택할 수 있는 컬러 팔레트가 추가된다
- AC4.3: BoxListPanel의 빈 상태에 아이콘 + 안내 문구가 개선된다 ("박스를 추가하세요" → 아이콘 + 설명 + 추가 버튼)
- AC4.4: 충돌 상태의 박스 카드에 경고 아이콘과 툴팁이 추가된다
- AC4.5: 다이얼로그 모서리, 간격, 폰트가 디자인 토큰(radius: 12px, gap: 12px)에 맞게 통일된다

**기술 노트:**
- `AddBoxDialog` 확장: 컬러 선택기 (8색 팔레트 그리드)
- `BoxListPanel` 빈 상태 위젯 교체
- 디자인 토큰 값은 `backlog/uiux.md` 참조

---

### Story 5: 스크린샷 내보내기 (P2 - 보통)
**목표:** 현재 트렁크 뷰를 PNG 이미지로 저장하여 공유할 수 있게 한다

**인수 조건 (AC):**
- AC5.1: 패널에 "스크린샷" 버튼이 추가된다
- AC5.2: 클릭 시 현재 캔버스 영역이 PNG로 캡처되어 브라우저 다운로드된다
- AC5.3: UI 패널은 캡처에 포함되지 않는다 (캔버스 영역만)
- AC5.4: 파일명 형식: `trimbox-{날짜시간}.png`

**기술 노트:**
- `RenderRepaintBoundary` + `toImage()` 사용
- 웹 환경: `dart:html` Blob 다운로드

---

### Story 6: 반응형 레이아웃 개선 (P2 - 보통)
**목표:** 모바일/태블릿에서도 쾌적하게 사용할 수 있도록 레이아웃을 개선한다

**인수 조건 (AC):**
- AC6.1: 600px 이하 화면에서 패널이 하단 시트(bottom sheet)로 전환된다
- AC6.2: 하단 시트는 드래그로 높이를 조절할 수 있다
- AC6.3: 트렁크 캔버스가 사용 가능한 공간에 맞게 동적으로 스케일 조정된다
- AC6.4: 터치 디바이스에서 박스 드래그 시 손가락 오프셋이 적용된다 (손가락 아래가 아닌 위에 박스 표시)

**기술 노트:**
- `LayoutBuilder` 분기점 수정 (현재 700px → 600px)
- `DraggableScrollableSheet` 활용 검토
- 터치 오프셋: `_onPanUpdate`에서 y 방향 -40px 보정

## 우선순위 & 의존성

```
P0 (필수)     P1 (높음)              P2 (보통)
─────────     ──────────             ──────────
Story 1  ──→  Story 2                Story 5
(Save/Load)   (프리셋)               (스크린샷)
              Story 3                Story 6
              (Undo/Redo)            (반응형)
              Story 4
              (UI 세련화)
```

- Story 1은 독립적, 가장 먼저 착수
- Story 2~4는 병렬 진행 가능
- Story 5는 Story 1의 파일 다운로드 패턴 재사용
- Story 6은 독립적이나 Story 4 이후 진행이 효율적
