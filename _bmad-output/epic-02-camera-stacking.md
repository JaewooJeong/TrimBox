# Epic 02: 3D 뷰 인터랙션 + 박스 스태킹

## 개요

카메라 줌/패닝/4방향 회전을 도입하여 트렁크를 다양한 각도에서 확인할 수 있게 하고, 박스를 다른 박스 위에 적재(스태킹)할 수 있도록 확장한다.

**선행 완료:** Epic 01 (MVP 완성도 향상) — 파일 Save/Load, 프리셋, Undo/Redo, UI 세련화

---

## Phase 1: 카메라 시스템

### Story 1: 마우스 휠 줌 인/아웃 (P0)
**목표:** 마우스 휠로 트렁크 뷰를 확대/축소할 수 있게 한다

**인수 조건 (AC):**
- AC1.1: 마우스 휠 위로 → 줌 인, 아래로 → 줌 아웃
- AC1.2: 줌 범위 제한 (최소 0.5x ~ 최대 3.0x)
- AC1.3: 줌 중심점은 마우스 커서 위치 기준
- AC1.4: 줌 레벨에 따라 드래그 좌표 역변환(`_screenToWorld`)이 정확히 동작한다
- AC1.5: 핀치 줌 (터치 디바이스) 지원

**기술 노트:**
- `_zoomLevel` 상태 추가, `GestureDetector.onScaleUpdate`로 휠/핀치 감지
- `IsometricPainter`에 줌 팩터 전달, 기존 dynamic scale과 곱연산
- `_screenToWorld` 역변환에 줌 오프셋 반영

---

### Story 2: 뷰 패닝 (P0)
**목표:** 줌 인 상태에서 뷰를 드래그하여 이동할 수 있게 한다

**인수 조건 (AC):**
- AC2.1: 우클릭 드래그 또는 미들 클릭 드래그로 뷰 패닝
- AC2.2: 터치 디바이스에서 두 손가락 드래그로 패닝
- AC2.3: 패닝은 줌 레벨에 비례하여 동작한다
- AC2.4: 박스 드래그(좌클릭)와 패닝(우클릭)이 충돌하지 않는다
- AC2.5: `_screenToWorld` 역변환에 패닝 오프셋 반영

**기술 노트:**
- `_panOffset` (Offset) 상태 추가
- `IsometricPainter`에 패닝 오프셋 전달, canvas translate 적용
- 좌클릭=박스 드래그, 우클릭/미들=패닝으로 분기

**의존성:** S1 (줌 레벨이 패닝 속도에 영향)

---

### Story 3: 4방향 회전 (P0)
**목표:** 트렁크를 4방향(0°, 90°, 180°, 270°)으로 회전하여 다양한 각도에서 볼 수 있게 한다

**인수 조건 (AC):**
- AC3.1: 4개 방향 프리셋 회전 (0°=현재, 90°, 180°, 270°)
- AC3.2: 각 방향에서 올바른 3면이 렌더링된다 (face visibility 룩업)
- AC3.3: 깊이 정렬(painter's algorithm)이 회전 방향에 맞게 동작한다
- AC3.4: 벽면/바닥/그리드가 회전 방향에 맞게 렌더링된다
- AC3.5: 휠하우스 위치가 회전에 맞게 변환된다
- AC3.6: `_screenToWorld` 역변환이 현재 회전 방향을 반영한다
- AC3.7: 박스 드래그가 모든 회전 방향에서 정확히 동작한다

**기술 노트:**
- `_cameraDir` enum (dir0, dir1, dir2, dir3)
- 프로젝션 공식 회전별 변환:
  - dir0: `sx=(x-z)*cos30`, `sy=(x+z)*sin30 - y` (현재)
  - dir1: `sx=(z-x)*cos30` 계열, x↔z 부호 변경
  - dir2: `sx=(z-x)*cos30` 계열, 반전
  - dir3: `sx=(x-z)*cos30` 계열, 반전
- face visibility 룩업 테이블 (방향별 top/left/right/front/back 조합)
- 깊이 정렬 키도 방향별로 변경

**의존성:** 없음 (S1과 병렬 가능)

---

### Story 4: 회전 UI + 전환 애니메이션 (P1)
**목표:** 직관적인 회전 컨트롤과 부드러운 전환 제공

**인수 조건 (AC):**
- AC4.1: 캔버스 위에 회전 버튼 (좌회전/우회전) 오버레이 표시
- AC4.2: 키보드 단축키: Q(좌회전), E(우회전)
- AC4.3: 회전 전환 시 부드러운 애니메이션 (200~300ms)
- AC4.4: 현재 방향 표시 인디케이터 (N/E/S/W 또는 화살표)

**기술 노트:**
- `AnimationController`로 프로젝션 파라미터 보간
- 캔버스 위 `Positioned` 위젯으로 회전 버튼 배치

**의존성:** S3

## Phase 2: 박스 스태킹

### Story 5: 박스 Y축 배치 (P0)
**목표:** 박스를 다른 박스 위에 놓을 수 있게 한다

**인수 조건 (AC):**
- AC5.1: 박스를 드래그하여 다른 박스 위에 놓으면 y 좌표가 아래 박스 상단으로 설정된다
- AC5.2: 바닥에 놓으면 y=0으로 유지된다
- AC5.3: 적재 시 아래 박스의 XZ 범위 내에 충분히 겹쳐야 한다 (50% 이상)
- AC5.4: 다단 적재 가능 (박스 A 위에 B, B 위에 C)
- AC5.5: 트렁크 높이(h) 초과 시 충돌로 표시된다

**기술 노트:**
- `TrimBox`에 `y` 속성 추가 (현재는 암시적 0)
- 드래그 종료 시 아래 박스 탐색 → y 자동 설정
- 프로젝션에서 y 값 반영 (이미 공식에 포함)

**의존성:** S3 (회전 방향에서의 정확한 렌더링 필요)

---

### Story 6: 적재 가능 영역 감지 + 시각 피드백 (P0)
**목표:** 드래그 중 적재 가능 위치를 시각적으로 표시한다

**인수 조건 (AC):**
- AC6.1: 박스 드래그 중 아래 박스 상단에 적재 가능 영역이 하이라이트된다
- AC6.2: 적재 불가 위치 (면적 부족, 높이 초과)에서는 빨간색으로 표시
- AC6.3: 적재 가능 위치에서는 초록색 가이드라인 표시
- AC6.4: 드롭 시 가장 가까운 적재면에 스냅

**기술 노트:**
- 드래그 중 후보 적재면 계산 로직
- `IsometricPainter`에 적재 가이드 렌더링 추가

**의존성:** S5

---

### Story 7: 중력/낙하 처리 (P1)
**목표:** 아래 박스가 제거되면 위의 박스가 자연스럽게 내려온다

**인수 조건 (AC):**
- AC7.1: 아래 박스 삭제 시 위에 있던 박스가 아래로 떨어진다
- AC7.2: 낙하 후 다른 박스 위 또는 바닥에 안착한다
- AC7.3: 아래 박스 이동 시에도 위 박스가 따라 내려온다 (지지면 이탈 시)
- AC7.4: Undo/Redo가 중력 결과를 포함하여 복원한다

**기술 노트:**
- `_resolveGravity()` — 모든 박스의 y를 아래에서 위로 재계산
- 박스 삭제/이동 후 자동 호출

**의존성:** S5

---

### Story 8: 3D 충돌 감지 확장 (P0)
**목표:** 충돌 감지를 2D(XZ) → 3D(XYZ)로 확장한다

**인수 조건 (AC):**
- AC8.1: 박스 간 3D AABB 충돌 감지 (X, Y, Z 모두 겹침 시 충돌)
- AC8.2: 높이 방향 경계 초과 감지 (y + h > space.h)
- AC8.3: 기존 휠하우스 충돌도 Y축 포함 (휠하우스 높이 위의 박스는 충돌 아님)
- AC8.4: 충돌 시각 피드백은 기존과 동일 (빨간 테두리 + 경고 아이콘)

**기술 노트:**
- `CollisionDetector` 확장: AABB 3축 겹침 판정
- 휠하우스 충돌에 y 범위 조건 추가

**의존성:** S5

## 우선순위 & 의존성 그래프

```
Phase 1 (카메라)                    Phase 2 (스태킹)
──────────────                     ──────────────
S1 (줌) ──┬──→ S2 (패닝)           S5 (Y축 배치) ──┬──→ S6 (적재 감지)
          │                                       ├──→ S7 (중력)
S3 (회전) ─┴──→ S4 (회전 UI)  ──→                  └──→ S8 (3D 충돌)
     ↑                              ↑
     └── 병렬 가능 ──┘              S3 완료 후 착수
```
